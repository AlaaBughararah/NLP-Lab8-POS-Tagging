# NLP Lab 8: Part-of-Speech Tagging

This lab explores part-of-speech (POS) tagging using NLTK and spaCy.

## Lab Activities

- Tag words using NLTK.
- Extract adjectives from text.
- Explore coarse-grained and fine-grained POS tags using spaCy.

## Tasks

1. Identify the POS tag of “play” and display tags and explanations for all tokens.
2. Compare the grammatical roles of “Google/google” and “table” in different contexts.
3. Visualize POS tags and grammatical dependencies using spaCy’s displaCy.

## Tools

- Python
- Jupyter Notebook
- NLTK
- spaCy
- displaCy
